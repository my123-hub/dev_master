## M2 后台基础模块（commit d109ef4，已推送）

**范围**：后端 7 类接口（25 项冒烟通过）+ 后台前端工程（登录/Dashboard/产品系列/产品/新闻/内容/首页配置 + 富文本/图片上传）。

**关键决策/坑**：
- 产品系列/新闻栏目删除保护（409 关联计数）；产品编号唯一（409）；soft delete is_activate=0。
- sys_config 键值对配置：批量保存（按 config_key 定位，存在更新/不存在自动创建）。
- 富文本清洗：依赖后端 Pydantic + 上传图片走 /upload 统一接口（类型白名单 jpg/png/webp、≤5MB、uuid4 文件名）。
- 上传接口 perm：开发技术文档 §6.3.11 标注"upload 或随模块"，种子无独立 upload 权限点 → 仅需登录即可（content_editor / super_admin 都能上传）。
- **端口冲突坑**：uvicorn 启动失败（8001 被旧进程占用）→ 新服务绑定失败，旧进程仍在响应 → 端口被静默占用。修复：PowerShell Stop-Process 杀旧进程；启动新服务前应 netstat 检查。
- **axios 类型增强**：响应拦截器解包 res.data 后，TS 仍按 AxiosResponse<T> 标注 → declare module 'axios' 重载方法签名返回 Promise<T>。
- **vite @/ 别名**：tsconfig paths 仅 TS 侧生效，Vite 需要 resolve.alias + fileURLToPath 同步路径。
- 受管 node 22.22.2 + npm 安装耗时 8m36s（含 wangEditor 4 个已知漏洞，开发期可接受；停维护 wangEditor 后续替换评估）。
